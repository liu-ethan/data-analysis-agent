data-analysis-agent [GitHub链接]：面向电商经营分析场景，构建可控、可澄清、可评测的 Text-to-SQL 智能分析助手，覆盖自然语言问数、指标与 Schema 匹配、SQL 安全执行、图表规划与结论输出

- 意图结构化：基于 LangGraph 编排分析链路；意图阶段先将模糊需求转为 AnalysisSpec JSON 槽位（指标、维度、时间、过滤等业务表达），避免过早猜测表名字段名导致幻觉，把物理 Schema 匹配留给后续检索与精排阶段完成
- Schema Linking：为了解决 Schema 选择易幻觉、完整表结构注入 Token 过高的问题，开发规则/BM25/向量召回与 Schema Linker 两阶段链路，先精排出含关联表字段的明确 Spec，再生成 SQL，相关表结构命中率约 85%，单次 Prompt Token 降低约 40%
- 语义澄清：为了解决指标口径与字段语义歧义时模型静默决策的问题，引入 Human-in-the-Loop，在歧义会改变 SQL 语义时结构化追问并由用户确认后恢复工作流，降低错误口径落库风险
- SQL 安全：为了解决生成 SQL 不可信且失败后难恢复的问题，开发 AST 校验、按角色授权执行与有限修复模块；Analyst 仅允许只读查询，Admin 允许业务表读写，统一禁止 DROP/ALTER/TRUNCATE 等破坏表结构操作；非法字段执行前拦截，失败后定向修复最多 2 次，避免无界 Agent Loop 
- 指标与评测：沉淀 GMV、订单数、客单价等 8 类指标 YAML；构建回归测试集，评估 Schema Recall@K、Execution Accuracy、澄清与修复成功率，并以 Schema fingerprint 阻断失效口径
